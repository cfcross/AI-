# 文案白名单池（demo 统一版）

商贩给不出文案时，**从本池按品类挑选组合，不现场编写**。
每条都是中性、不夸大、不涉及具体时刻/产地/年份的通用说法——
若商户自己提供了更具体的信息（如"每天 5 点到货"），以商户为准。

## 字段对应
- 价目表：`sub`（店名下一行）选 1 条；`foot`（底部卖点）1–2 条用 ` · ` 连接；`note` 需要时选 1 条；`hours` 商户没给就留空。
- 海报：`line`（底部卖点）选 1 条；`side1`/`side2`（竖排，**各 4 字**）从同品类挑一对；`cat` 用 `品类 · 区域`，区域不明只写品类。
- 店名不在本池（不能当文案挑），按 SKILL.md「店名代拟」规则补，并在确认行里说出来。

## 店名代拟的词形（只借结构，不整句照搬）
- `老` / `小` + 姓 + 品类 → 老李鱼档、小陈肉档
- 姓 + `记` + 品类 → 陈记烧腊、李记鲜肉
- `阿` + 名 + 品类 → 阿珍菜档、强仔水果
- 位置 + 品类 → 巷口鲜肉、市场尾鱼档
- 品类 + `档` → 鲜鱼档、烧腊档

禁用词：正宗、第一、最、老字号、祖传、百年、专营、有限公司（招牌不是执照，别给自己揽责任）。

## 海报底图主体（AI 生图用）
底图提示词由引擎生成，不必手写：

```bash
python assets/poster_a.py --print-prompt --cat 水产
python assets/poster_a.py --print-prompt --cat 烧腊 --subject "挂满烧鹅的档口近景，油光反光"
```

内置主体按品类落在 `assets/poster_a.py` 的 `SUBJECT` 里（水产/烧腊/肉档/蔬菜/水果/小吃/兜底）。
想换构图只换 `--subject` 这一句，别的（近景大特写、暖黄吊灯轮廓光、下方压暗留白、不要文字）都别动。
