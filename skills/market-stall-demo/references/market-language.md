# 菜市场语言理解与纠偏

词表在同目录 `market-lexicon.json`：categories 是用户平面图的22类、市场明细里的明确品名和常见商品扩充；venue_groups 是场所语义组；alias_groups 是地方叫法；confusions 是需上下文验证的误识别候选；never_merge 是不可擅自合并的商品。词表不是实时库存、价格、产地或真实店名名单。registered_store_names 目前为空，待现场调研。

## 市场提供的明细

`market-catalog.json` 按原 Excel 的行号保存209条品名与规格依据，不包含价格。来源工作表明确写着“价格为时价”，还存在同名不同价及不同计价单位，不能作为无人确认的报价表。原始含价记录只在本机留档。

- `listed` 只表示原表列出，不代表当前库存或物种已经鉴定；`needs_review` 表示原文或括号含义待核实。原表分类与语言分类分别保存：如粮油类里的油麦菜按蔬菜理解，不据此推断商户属于哪家店。
- 不因表中列出某商品就添加到本轮订单，不把多条规格候选全部画出来。只使用用户要求的商品与规格。价格、单位、数量始终来自本轮口述，不按表价覆盖，不用旧价格补缺，不平均或取最低价。用户只说“按市场价”但没有当前明确报价时，价格牌按协议 `needs_input`；无价海报可继续。
- 保留大闸蟹的公母、两数，花螺大小，濑尿虾大小及有膏，白鳝脆/不脆，马鲛丸纯鱼肉/含猪肉，以及冰鲜/冷冻/熟食等限定。未知限定不能从同名记录推测。斤、两、只、个、包不可因参考表自动互换。
- 雪龙（雪花牛肉）、鱼虾、牛腱羊肉、文肠、唐山（山西）、洋姜（黄姜）、芋头（红头）、老虾（中）已标记待核实。不要把括号内容一律当别名；不要猜“唐山”是淮山、“老虾”是龙虾。独立“芋头”“洋姜”仍可按原词理解。菜芯/菜心、泥猛/泥猛鱼等有明确别名线索时保留用户写法，用于理解图片主体。
- 基围虾存在计价单位不一致的记录；东星斑、黄花鱼存在不同报价记录。这不证明某行错误，也不能把用户说的金额纠成表中金额。

## 先明确角色，再进行设计

1. 已登记或明确“店名叫/招牌写”的名称优先保护。名字特殊不是纠错理由。没有店名时记录未提供，再按代拟规则产生泛称，并在 summary 标注。不要把“做一张东星斑的海报”解释成店名叫东星斑。
2. “海鲜市场/鱼类集市/鱼类市集/鱼摊/水产档”同属水产销售意图，能推断画面主题；保留用户描述的市场、集市、单摊规模和原叫法。市场海报不自动变成单家鱼档广告，不能从场所名推导任意商品价格。
3. 商品与菜品要区分：“鱼汤十五元一碗”是菜品；“给我的鱼汤做个招牌”可能是鱼摊误识别，但若用户明确把鱼汤作为店名、菜名或品牌，应保留。孤立“鱼汤海报”保留鱼汤，不自动纠成鱼摊。
4. 罗非鱼/鲈鱼、龙利鱼/巴沙鱼、普通草鱼/脆肉鲩、鳕鱼/银鳕鱼不能仅凭语义接近互换。保留品种、部位、规格、产地限定及每个数字/单位。

## 电话自动化任务

程序的 language_analysis 已在网页展示前完成保守词表纠偏，text 是最终文字；raw_text、edits 是审计记录；terms/venues 是基于词表的角色线索，不能把它们当作完整商品订单（否定、举例、比较中的词也可能命中）。protected_names 必须保留，uncertain 只是候选，不是批准替换。

`terms[].canonical_hint` 是地方叫法的理解线索，不是必须更改显示文字的指令。`catalog_context.matches` 是相关原表行与规格候选，不是本轮已选商品；`source_review` 是保留原词的来源疑点，不是纠错目标。仅在这些线索不足时查询相应参考文件，避免逐轮读取全部209行。

- 采用已校正的 transcript 和 edits，原文仅用于理解和追溯，不能把已纠正的错字再恢复。
- 对 uncertain 和词表外词结合完整语境理解，但不要在生图阶段偷偷改商品、金额、单位或店名，造成网页和图片不一致。原文存在完整合理解释时保留；核心商品确实无法判定时按调用方协议 needs_input。手动聊天可简短询问。
- 优先使用任务内 terms/venues；仅需额外领域知识时读取词表相应类别，不每轮研究整本词表，不新增生图候选轮次。
- 提交 design 前检查：店名来自明确命名或标明代拟；画面商品来自最终需求；价格数字和单位与原文对应。用正常语言理解否定和范围，例如“不要罗非鱼，要鲈鱼”只画鲈鱼，“鱼汤不要改成鱼摊”保留鱼汤。

## 判例

| 输入 | 处理 |
| --- | --- |
| 东兴班每斤八十八元 | 商品候选东星斑，88元/斤；未提供店名 |
| 帮我做一张东兴班的海报 | 商品主题东星斑；不能用东兴班作店名 |
| 店名叫东兴班，卖鲈鱼 | 店名东兴班，商品鲈鱼 |
| 东兴班海鲜档，帮我做海报 | 可能的真实档口名，保留名称 |
| 给我的鱼汤做个招牌 | 程序存在明确场所依据时校正鱼摊；明确命名优先 |
| 鱼汤十五元一碗 / 做一张鱼汤海报 | 保留鱼汤 |
| 鱼类市集海报 / 海鲜市场海报 | 水产集市/市场场景，不擅自缩成单摊 |
| 濑尿虾、通菜、牛展 | 理解地方叫法，保留用户的用词 |
| 马交鱼每斤三十元 / 盐局鸡每斤二十九元 | 商品上下文校正马鲛鱼/盐焗鸡；金额单位不变 |
| 店名叫马交鱼，卖盐焗鸡 | 特殊店名保留马交鱼 |
| 大闸蟹2.5两母的，80元一只 | 公母、规格和计价单位全部保留；不追加公蟹或其他规格 |
| 白鳝不脆65元一斤，马鲛丸纯马鲛45元一斤 | 不脆与纯鱼肉限定保留，不能按参考候选换成脆/含猪肉 |
| 唐山（山西）12元一斤 | 保留原词，核心商品无法判定时 needs_input，不猜淮山 |

## 维护

真实错例先进入 confusions，再在项目 tests/test_market_language.py 添加正例、反例和特殊店名例。不能把同音词全部加入无条件替换表。不要从一次对话自动学习价格、真实店名或新替换规则。普通话/粤语均使用规范汉字词表；当前本地纠偏是显式候选和上下文规则，不是通用拼音/粤拼模糊匹配模型。
